どんなゲーム？

ローグ・クローンII は、古典的なダンジョン RPG「Rogue」を再現したゲームです。目的は、地下 27 階に眠る宝「イェルダーの魔除け」を手に入れて地上に持ち帰ること。

ダンジョンは冒険のたびに作り直されるので、毎回ちがう地形、ちがうアイテム、ちがう怪物に出会えます。画面は文字だけで描かれ、ターン制で進むので、じっくり考えながら遊べます。

ここで紹介している移植版は、どちらも日本語のメッセージで遊べます。英語のメッセージファイルも同梱しています。

移植版

X68000 版

RogueClone2X68k

「データ分離版ローグ・クローンII」を X68000 / X68000 Z 用にビルドしたものです。

  • C
  • X68000
  • X68000 Z
  • Human68k

入っているもの

  • rogue.x … ゲーム本体
  • Rogue.xdf … 一式を収めたディスクイメージ
  • start_rogue.bat … プレイ・スコア表示を選べるメニュー
  • msg/mesg（日本語）、msg/mesg_E（英語）… メッセージファイル

遊び方

メニューから始めるときは start_rogue、直接始めるときはメッセージファイルを指定して起動します。

A>start_rogue
  1: rogueをプレイ / 2: スコア表示 / q: 終了
  （1 を選ぶとプレイヤー名を聞かれます）

A>rogue msg\mesg       … 直接プレイ
A>rogue msg\mesg -s    … スコアを表示

動作確認

  • XM6 TypeG（エミュレータ）と X68000 Z で起動を確認しています。
  • X68000 の実機ではテストしていません。

Raspberry Pi 版

RogueClone2Pi

鈴木維一郎氏の「rogueclone2（UTF-8 版）」を、Raspberry Pi のターミナルで正しく表示されるように直したものです。

  • C
  • Raspberry Pi
  • Linux
  • ncurses
  • UTF-8

元の版からの主な変更

  • 背景色を透過するようにしました（ターミナルの背景色がそのまま使えます）
  • スコアのランキングを UTF-8 で正しく表示できるようにしました
  • ニックネームを使ったときのランキング表示を直しました
  • ビルド時の警告に対応しました

ビルドと起動

# 必要なパッケージを入れる
$ sudo apt install -y automake \
    libncurses5-dev libncursesw5-dev

# ビルド
$ autoreconf -i
$ ./configure
$ make clean
$ make
$ cp src/rogue .

# 起動（英語で遊ぶときは mesg_E）
$ ./rogue mesg

系譜

ローグ・クローンII は、多くの人の手を経て受け継がれてきました。ここで紹介している移植版は、次の流れの上にあります。

  1. Rogue Clone — Tim Stoehr 氏 Rogue を再現したゲーム。ソースコードが公開され、ここからさまざまな版が生まれました。
  2. ローグ・クローン2 日本語版 1.3 — 太田純 氏 日本語化した版。
  3. データ分離版ローグ・クローンII — 伊藤康史 氏 メッセージをデータファイルに分け、言語を切り替えられるようにした版。
    → X68000 版（RogueClone2X68k）はここから。X68000 / X68000 Z 向けにビルドしました。
  4. rogueclone2s — FUNABARA Masao 氏 データ分離版のメンテナンスバージョン。
  5. rogueclone2s-utf8 — Naohiro Aota 氏 ターミナルへの出力を UTF-8 に対応させた版。
  6. rogueclone2（UTF-8 版） — 鈴木維一郎 氏 メッセージファイルやソースコードも含め、すべてを UTF-8 にした版。
  7. RogueClone2Pi — yagennankoz Raspberry Pi での表示の不具合を直した版。

ライセンス

ライセンスは、元になった「データ分離版ローグ・クローンII」と「ローグ・クローン２ 日本語版１.３」の条件に従います。詳しくは各リポジトリに同梱しているドキュメント（RogueClone2Pi の COPYING、RogueClone2X68k の original_doc/）をご覧ください。
