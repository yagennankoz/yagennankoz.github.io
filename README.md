# yagennankoz.github.io

GitHub で公開しているプロジェクトのポータルサイトです。

**https://yagennankoz.github.io/**

## プロジェクトを追加するとき

1. `index.html` の該当するカテゴリの `<div class="grid">` の中に、既存のカード（`<a class="card" ...>` 〜 `</a>`）を1つコピーして書き換えます。
2. 写真がある場合は、横 800px 程度に縮小して `images/` に置き、`<div class="thumb"><img ...></div>` で指定します。写真が無い場合は `<div class="thumb screen mono">` の「画面」風サムネイルを使います。
3. プロフィール README（[yagennankoz/yagennankoz](https://github.com/yagennankoz/yagennankoz)）の一覧にも1行追加します。

写真の EXIF（撮影場所の GPS 情報など）は、`images/` に置く前に削除してください。
